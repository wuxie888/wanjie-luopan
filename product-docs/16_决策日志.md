# 决策日志

## D-001 先 Skill 后产品

决定：先稳定筛选内核，不直接开发 UI。

原因：UI 会固化尚未验证的字段和流程；Skill 可最低成本获取真实任务证据。

## D-002 默认目标是“值得看”

决定：删除变现导向，不把二次开发和商用当作每次搜索的默认目的。

## D-003 渐进验证

决定：默认快速发现；深查和运行必须按用户请求升级。

## D-004 品牌名与机器标识统一

决定：总品牌为“万界罗盘”，机器标识和 Skill 目录统一使用 `wanjie-luopan`。

## D-005 项目源码与全局安装分离

决定：当前目录保留可维护源码，验证后同步到全局 Skill 目录。

## D-006 主动发现与持续发现属于同一产品

决定：不在“按需搜索 Agent”和“持续发现产品”之间二选一。两者共享项目身份、证据、研究记录和关系底座。

## D-007 建立统一产品语言

决定：使用“路引、巡天、星图、开卷、星历、藏卷、舆图”命名核心能力。当前 Skill 只声明已经实现的路引、基础星图、开卷和按需运行验证。
