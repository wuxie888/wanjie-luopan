# 品牌资产

万界罗盘的视觉母题是“现代舆图 × 证据路线”。

## 核心资产

- `logo-mark.svg`：透明背景主标志
- `logo-lockup.svg`：横向品牌组合
- `icon.svg` / `icon.png`：Codex Skill 方形图标
- `hero.svg` / `hero.png`：README 静态 Hero，1440×560
- `social-preview.svg` / `social-preview.png`：GitHub Social Preview

## 视觉规则

| Token | 色值 | 用途 |
| --- | --- | --- |
| Ink | `#0B1C31` | 主文字、结构线和深色背景 |
| Paper | `#F4F0E6` | 大面积浅色背景 |
| Vermilion | `#D45D3F` | 路线、节点和唯一强调色 |
| Slate | `#607086` | 次要文字 |
| Rule | `#D8D1C3` | 网格与分隔线 |

- Hero 使用 `#07131F` 至 `#17324B` 的深色表面层级，仍只用朱橙标记路线和证据节点
- 不使用星尘、占星圆环、金色纹理或假 Dashboard
- 路线和节点表达“来源 → 核验 → 证据 → 路引”
- 小尺寸图标只保留折叠舆图和一条路线
- Social Preview 保持 1280×640 且小于 1 MB

这些矢量资产为本仓库原创，不包含外部字体文件或第三方图标路径，随仓库按 MIT License 发布。
