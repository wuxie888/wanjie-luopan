# 产品总体方案

## 产品内核

万界罗盘由两条发现路径和一个共享研究底座组成：

- 主动发现：用户给出方向，经“路引 → 星图 → 开卷 → 最小运行验证”逐级深入
- 持续发现：系统通过“巡天 → 星历”发现新项目和重要变化
- 共享底座：通过“藏卷 → 舆图”保存项目档案、研究记录和项目关系

两条路径不是两个产品。主动搜索、持续推荐、个人收藏和长期追踪共享同一套项目身份、证据等级和研究记录。

## 当前 Skill 工作流

采用四级渐进工作流：

1. 路引：快速发现
2. 星图：候选对比
3. 开卷：仓库深查
4. 最小运行验证

用户只说“找项目”时停在路引，输出 3–8 个分层候选；不自动克隆、安装或推荐变现。

## 判断模型

先使用硬门槛排除不存在、空壳、不相关、许可证冲突和核心依赖失效项目，再使用相关度、独特性、完整度、活跃度、文档、使用证据和法律清晰度排序。

## 证据模型

- E0：线索
- E1：仓库表面证据
- E2：工程证据
- E3：运行证据

## 产品形态

当 Skill 稳定后，产品 UI 复用同一内核，形成：

- 路引：按需搜索任务与分层短名单
- 巡天：持续发现流
- 星图：候选对比与生态关系
- 开卷：项目研究详情
- 星历：版本、维护和社区变化
- 藏卷：个人项目库
- 舆图：跨任务项目知识图谱

## 真实性边界

当前已实现的是 Skill 形态下的路引、基础星图、开卷和按需运行验证。巡天、星历、藏卷和舆图仍是产品规划，不能因完成品牌命名而宣称已经具备。
