# 风险评估

| 风险 | 影响 | 控制方式 |
| --- | --- | --- |
| 编造仓库或过期指标 | 高 | 使用原始来源并标记检查时间 |
| README 被当作事实 | 高 | 使用 E0–E3 证据等级 |
| Star 偏见 | 中 | Star 不进入核心评分字段 |
| 总分掩盖硬风险 | 高 | 硬门槛优先于评分 |
| 搜索范围无限扩大 | 中 | 10–20 候选池与停止规则 |
| 默认执行陌生代码 | 高 | 运行验证必须明确触发并隔离 |
| 许可证判断过度承诺 | 高 | 使用风险分层并提示以原文为准 |
| Skill 与全局安装副本漂移 | 中 | 安装后比较文件清单与校验结果 |
