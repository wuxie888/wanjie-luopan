# 万界罗盘 v0.1.0

给一个方向，得到一份有证据的开源项目路引。

这是万界罗盘的首个版本化公开发布。它把已经可用的 Codex Skill、真实第一次成功路径和完整仓库说明放到同一个可安装版本中。

## 这一版包含

- 路引、基础星图、开卷与按需最小运行验证
- E0–E3 证据分层、硬门槛、许可证与事实冲突边界
- 仅依赖 Python 标准库的确定性候选评分器
- 60 秒安装、第一次成功、更新、卸载与排错文档
- 一份真实的 macOS 本地语音转文字项目路引样例
- GitHub Actions 结构校验与 4 项评分器回归测试
- 统一的 Logo、静态 Hero、图标与 Social Preview

## 安装

```bash
git clone --branch v0.1.0 --depth 1 https://github.com/wuxie888/wanjie-luopan.git
mkdir -p "$HOME/.codex/skills/wanjie-luopan"
rsync -a --delete wanjie-luopan/wanjie-luopan/ "$HOME/.codex/skills/wanjie-luopan/"
```

安装后新建一个 Codex 任务，再调用 `$wanjie-luopan`。

完整步骤见 [上手指南](https://github.com/wuxie888/wanjie-luopan/blob/v0.1.0/docs/GETTING_STARTED.md)，遇到目录嵌套、Skill 不出现或结果时效性问题时查看 [排错指南](https://github.com/wuxie888/wanjie-luopan/blob/v0.1.0/docs/TROUBLESHOOTING.md)。

## 验证

- 公开 `main` 提交通过 GitHub Actions `Validate Skill`
- 从公开仓库全新克隆和临时安装通过 Skill 结构校验
- 评分器 4 项回归测试通过
- 独立真实发现任务通过，且没有在默认路引中克隆、安装或运行陌生候选

## 当前边界

这一版是本地 Codex Skill，不是独立 App、网站或云服务。巡天、星历、藏卷和舆图仍属于后续产品规划。
