# 来源拆解记录

## 来源概述

X 帖提供一段让 Codex 搜索 3–5 个开源候选、比较优劣并推荐最优项目的提示词，同时宣称可用于快速变现。

## 原始价值

- 把模糊目标变成结构化搜索任务
- 固定候选数量和比较维度
- 要求给出风险与下一步

## 已验证缺口

- 没有要求核对 README 与源码
- 没有运行、测试、Release 和 Issues 门槛
- 缺少许可证、素材和依赖边界
- “节省 Token”与“变现”没有证据
- 引用的热门仓库仍存在闪退、兼容性、杀软和发行产物问题

## 转化原则

保留发现与对比流程，删除变现导向，加入真实来源、硬门槛、证据等级、渐进深查和最小运行验证。
