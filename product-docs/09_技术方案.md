## 执行方式

- 搜索和时效数据：使用当前可用的官方 GitHub 页面/API或用户指定浏览器
- 证据判断：按 E0–E3 层级组织
- 排序：`scripts/score_candidates.py` 读取候选 JSON，先执行硬门槛再评分
- 深查：读取真实文件、入口、依赖、测试、Release 和 Issues
- 运行：仅对最终 1–2 个项目在隔离目录执行

## 依赖

评分脚本仅使用 Python 标准库。Skill 不绑定某个浏览器或 GitHub 连接器，按当前环境选择可验证的最佳来源。
