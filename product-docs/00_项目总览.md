# 万界罗盘｜项目总览

## 一句话产品

万界罗盘是个人开源项目发现与研究系统：既能按一个模糊方向主动寻找项目，也能持续发现、收藏和追踪值得看的项目。

## 品牌主张

为每个想法找到方向，在开源万界中留下自己的星图。

## 目标用户

- 主要用户：经常让 Codex 寻找、比较和深查 GitHub/开源项目的个人开发者
- 次要用户：技术研究、产品探索和二次开发选型人员
- 明确不服务：只想按 Star 排行、自动包装售卖或无需证据的流量型榜单用户

## 核心问题

现有搜索能找到关键词相似的仓库，却不能稳定回答哪些是真项目、哪些值得打开、证据到哪一层。

## 核心价值

减少重复搜索和无效仓库阅读，把一次性搜索摘要升级为可追溯、可积累、可持续更新的个人项目知识资产。

## 使用场景

- 从一个想法寻找现成实现
- 浏览近期出现或重新活跃的项目
- 比较多个候选仓库
- 完整检查某个仓库
- 对最终项目做最小运行验证
- 收藏项目并持续追踪后续变化

## 产品语言

| 名称 | 产品含义 | 当前状态 |
| --- | --- | --- |
| 路引 | 从一个方向主动寻找并生成项目短名单 | Skill 已实现 |
| 星图 | 比较候选并呈现项目、作者、技术与生态关系 | Skill 部分实现 |
| 开卷 | 打开单个项目进行完整研究 | Skill 已实现 |
| 巡天 | 持续扫描新项目、趋势和重新活跃的项目 | 产品规划 |
| 星历 | 跟踪提交、Release、Issue 和维护变化 | 产品规划 |
| 藏卷 | 个人收藏、研究记录和项目库 | 产品规划 |
| 舆图 | 连接全部项目档案与关系的知识底座 | 产品规划 |
